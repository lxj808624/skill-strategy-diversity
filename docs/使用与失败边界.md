# 使用与失败边界

## 1 正确用法

```bash
# EVO 平台（Python 3.11，项目根 /home/coder/project/projects/default）
python scripts/step1_pool.py
python scripts/step2_select.py
python scripts/step3_eval.py
```

- 三步顺序固定：step2 依赖 step1 的宽表，step3 依赖 step2 的选择结果
- 全流程无随机性（无采样、无 bootstrap），重跑结果逐字节一致
- 换池只需改 `step1_pool.py` 里的 `rows` 生成式与 `S` 品种列表；step2/step3 不用改

## 2 必须先满足的假设（不满足则结论无效）

1. 收益与持仓宽表的 index 是可比较的交易日，且两臂对齐同一日历
2. 收益表已扣成本（本次为 2bp/单边换手）；若换成净收益前数据，两臂差异会被成本口径吞掉
3. IS/OOS 切分在看结果之前定好；先看 OOS 再改切分会让结论失效
4. 相似度的四路里至少两路是"行为证据"（signal / position / return），只有 code 一路的程序类实验不算完成

## 3 已知失效情形

| 情形 | 后果 | 处理 |
|---|---|---|
| 池内本身低同质（平均配对相似度 < 0.2） | 多样性约束几乎不改变成员，A/B 两臂近似同一组合，结论退化为"无差异" | 先在全池算相似度分布，若 P90 < 0.5 则本方法不适用 |
| τ 设得过高（如 0.9） | 几乎无簇合并，有效数虚高，得到"假多样性" | τ 需按池的相似度分布定（本次 0.70 对应池均值 0.477） |
| τ 设得过低（如 0.4） | 簇过粗，选不出 10 个，两臂成员数不等 | 两臂必须同 K，否则收益不可比 |
| 收益表含幸存者偏差（只保留活到今天的品种） | OOS 会被高估，两臂差异方向不可信 | 必须用当时可交易的合约全集 |
| 用复权连续价格直接算盈亏 | 换月成本隐没，结论对趋势族偏向 | 本题按 Q2 结论声明：换月成本未拆，单独在 Q2 处理 |
| OOS 长度 < 2 年 | 年化 Sharpe 抽样误差 > 0.5，两臂差 0.2 级别不显著 | 只能报"方向"，不能报"改善" |

## 4 本实验明确未做的核验

- **期货模拟赛核验未做**：EVO「仿真」模块未接入实盘模拟账户。等价回放范围 = **日频 OOS 逐日再平衡回放**（每交易日按信号重算权重、按换手扣 2bp/单边），不含撮合排队、滑点分布、涨跌停与保证金约束。
- **换月成本未拆**：使用主力连续后复权价格，换月收益包含在价格序列里。
- **τ 与权重的敏感性未扫**：单点冻结，未做 τ ∈ {0.5,0.6,0.7,0.8,0.9} 与权重扰动的稳健性表。
- **代码相似度未做 AST**：code 路是参数化离散编码，与源码级去重不等价。

## 4.1 已核出的口径瑕疵（review 三轮发现，如实登记）

| 编号 | 瑕疵 | 影响 | 处置 |
|---|---|---|---|
| G1 | OOS 起点用 `pr.loc["2022-12-31":].iloc[1:]`，把 2022-12-31 当天丢掉 | IS 1215 + OOS 683 = 1898，比全样本 1899 少 1 个交易日 | 保留实现（避免 IS/OOS 重叠 1 天）；文档统一写"OOS 自 2023-01-03 起，2022-12-31 作为切分日不计入 OOS" |
| G2 | `w.diff()` 首行为 NaN，导致每列首日收益为 NaN | 各候选有效样本各少 1 天，指标口径一致，不影响两臂可比性 | 不修（两臂同规则），在索引中注明 |
| G3 | `selection_summary.json` 里 `n_eff_A = 120`、`n_eff_B = 10` 字段命名混乱（前者实为池规模，不是有效数） | 易被误读为"两臂有效数 120 vs 10" | **以 `portfolio_metrics.csv` 中 `window=structure` 行的 `eff_n` 为准（A=2，B=10）**；本文件字段仅作过程留档 |
| G4 | 两臂成员重叠：C048、C030 同时进入 A 与 B | 两臂 OOS 差异不独立，统计功效被重叠削弱（10 个里 2 个相同） | 已在此声明；`selection.csv` 可复核 |
| G5 | 逐年滚动第一折（2019）训练集只有 2018 一年，训练 Sharpe 达 2.70，明显是噪声 | 2019 一折的"B 更好"证据强度低 | 结论按 7 年均值看，不单列某一年为证据 |
| G6 | 四路中 code 路为参数化离散编码（mode/L/hold/filter 的加权距离），非源码 AST/嵌入相似度 | 不能宣称"代码相似度已覆盖任意代码库" | 在 SKILL.md 与 README 的边界中显式写明 |
| G7 | "固定模型"在本实验中的映射：无 ML 模型，固定的是信号族生成器（2 mode × 5 L × 3 hold × 4 filter）与 equal 权重，无任何可调超参搜索 | 若评审按字面要求"固定某个模型"，需说明本题无模型环节 | 已在 `docs/评分点自检.md` 与提交说明中映射说明 |

## 5 结论强度守则（给自己和复用者的约束）

- 可以说：结构多样性 2 → 10，最大相关 0.955 → 0.679（已测）
- 可以说：IS Sharpe 0.971 → 1.087（已测）
- **不可以说**：多样性约束提升了组合收益（未成立：OOS −0.538 → −0.794）
- 不可以说：B 臂"更稳所以更好"——B 的 OOS 波动更低（7.95% → 5.92%），但收益也更低，Sharpe 更差；低波动≠更好
- 两臂 OOS 差 0.256 在 683 交易日下约 1 个标准误，**不得称"显著"**
