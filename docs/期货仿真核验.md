## 3 与本题 2bp 假设的关系

- 本题用 **2bp/单边固定** 近似成本；平台用 **交易所品种费率表 + 1 跳滑点**，后者更接近真实（手续费按品种差异，滑点按最小变动价位）
- 平台口径下日均换手 2.92%、年化 7.4 倍，说明这个趋势族的换手不算低，2bp 的固定假设对它偏乐观
- **方向一致**：平台近两年夏普 −1.70，本题 OOS（2023-01~2025-10）两臂夏普分别为 −0.538 / −0.794，都在 0 以下 —— 趋势族在这段时间确实失效
- 不能直接等同的：平台这版是单因子（20 日截面趋势、gross 2.0、top 20），本题 A/B 臂是 10 个候选等权组合；且区间不同（2024-11~2026-11 vs 2023-01~2025-10）

## 5 等价回放范围（明确声明）

- 仿真盘是**前向纸面交易**（虚拟资金、服务器开机期间运行），**不是历史回放**；截至提交时点账户动态权益 1,000,000.00、累计收益 0.00%，尚无成交
- 因此本题的交易执行核验 = **平台真实成本口径的历史回测**（第 2 节，覆盖 2 年、含交易所费率与 1 跳滑点）+ **仿真盘执行链路已打通**（开户、启动、日志、账户号）
- 未覆盖：撮合排队、涨跌停无法成交、保证金强平、夜盘时段的具体成交分布；这些需要仿真盘在真实交易日累积数据后复核（同一仿真盘可继续跟踪，账户号已在上面给出）
- 品种范围：平台仿真盘与回测均按平台可交易商品期货品种池，本题实验池为 11 个品种（RB/I/CU/AU/AG/M/TA/MA/SC/P/Y），两者不完全一致

1. EVO → 研究(forge) → 新建作品 → 策略 / 期货 / 商品期货 → 定义方式「公式」
