# 冻结基线对照

## 1 冻结了什么（在跑第一步之前写死）

| 项 | 冻结值 | 冻结时点 |
|---|---|---|
| 候选池 | 2 mode × 5 L × 3 hold × 4 filter = 120 | 2026-11-18，`docs/研究设计.md` 写定后未改 |
| 权重方案 | equal（按 |signal| 归一） | 同上 |
| 信号→收益 | 信号 t，收益 t+1 | 同上 |
| 成本 | 2bp/单边，按换手计 | 同上 |
| IS / OOS 切分 | IS ≤ 2022-12-31；OOS 2023-01-03 ~ 2025-10-31 | 同上 |
| 四路权重 | 0.30 / 0.30 / 0.20 / 0.20 | 同上 |
| τ | 0.70 | 同上 |
| 两臂定义 | A 按 IS Sharpe top-10；B 同序遍历 + 每簇取 1，取满 10 | 同上 |

**没有任何参数在看到结果后调整。** 唯一的事后动作是 step3 末尾补了一行 `print(RB)`（纯展示，不改计算）。

## 2 基线是哪个

本题的冻结基线 = **A 臂（无多样性约束，IS Sharpe top-10 等权组合）**。它代表"现有常规做法"：批量生成 → 按 IS 指标挑前 10 → 等权建组合。

对照臂 = **B 臂（多样性约束）**。两臂同池、同预算、同模型、同费用、同切分，唯一差异是选择规则。

## 3 对照结果（摘要）

| 维度 | 基线 A | 对照 B | 差 |
|---|---|---|---|
| 有效独立策略数 | 2 | 10 | +8（5 倍） |
| 最大配对相似度 | 0.955 | 0.679 | −0.276 |
| IS Sharpe | 0.971 | 1.087 | +0.116 |
| IS 年化波动 | 14.39% | 9.81% | −4.58pp |
| IS 最大回撤 | −16.75% | −10.50% | +6.25pp |
| **OOS Sharpe** | **−0.538** | **−0.794** | **−0.256（变差）** |
| ALL Sharpe | 0.561 | 0.559 | −0.002 |
| 滚动胜率 | — | 3/7 年 | — |

## 4 为什么基线"看起来更好"却更危险

A 臂 IS Sharpe 0.971 建立在两个独立因子上（有效数 2），IS 波动 14.39%。它的高 Sharpe 来自**同一族的重复暴露被等权加权后放大了集中在 2020 段的行情的贡献**，不是来自分散。B 臂 IS Sharpe 更高（1.087）但波动更低（9.81%），是因为它真的分散了。

而在样本外，A 臂的"集中"反而给了它一点优势（−0.538 好于 −0.794），这恰恰说明：**在 OOS alpha 已经衰减到 0 的市场里，集中度高低只改变噪声的实现方式，不改变期望。**
