# 研究设计（冻结）：固定搜索预算下的策略多样性约束

任务：量枢院第四期题三（D=0.85，平台 EVO）。题目要求「固定任务、模型与搜索预算，比较有/无多样性约束；联合代码/信号/持仓/收益相似度识别重复，并检验有效策略数量与组合风险是否改善」。

本文在动手前冻结，后续脚本、报告、自检测试都以本文为准；任何偏离必须记录在报告「偏离声明」一节。

## 1. 研究问题

同一批候选策略、同一个搜索预算，两种保留（retention）规则：

- **臂 A（无多样性约束）**：按 IS Sharpe 取前 10。
- **臂 B（多样性约束）**：同样按 IS Sharpe 排序，贪心加入，直到已选集合内任意两策略的联合相似度 ≥ τ 或选满 10 个。

问题不是「哪个收益高」，而是：**加多样性约束后，有效策略数（去重后的独立策略数）是否上升，组合风险（波动、回撤、尾部）是否下降，以及这些改善在样本外还在不在。**

## 2. 平台与执行

- 平台：PandaAI EVO（`https://www.pandaaiquant.com/evo/pc113a4e548c9/modules/forge`），个人私有研究环境，按小时计费（10 算力/时）。
- 执行入口：EVO 研究助手 → `write_file` 落脚本 → `run_python_script` 在平台 Python 3.11 环境跑（单次 120s 上限），每次 run 有 runId 与 `result.json`，记录输入输出。
- 数据：平台 `panda_data` 的 `get_future_daily_post`（主力连续、后复权、价差法），2018-01-02~2025-10-31，12 个品种，21,387 行；实测落盘 `futures_daily.csv.gz`（414KB）。
- 不用 parquet（平台未装 pyarrow，且不为此改动平台环境）。

## 3. 数据与样本

- 品种：RB / I / CU / AU / AG / M / TA / MA / SC / P / Y 共 11 个。**LC 剔除**：碳酸锂 2023-07-21 才上市（552 行），进不了 2018–2022 样本内。
- IS（样本内）：2018-01-02 ~ 2022-12-31
- OOS（样本外）：2023-01-01 ~ 2025-10-31
- 交易日不补齐、不做前瞻填充；停牌/缺数据按「无仓位」处理。

## 4. 搜索预算（固定，两臂完全相同）

- 参数网格：mode ∈ {trend, reversal}；L ∈ {5,10,20,40,60}；hold ∈ {1,3,5}；filter ∈ {none, ma20, ma60, volcap}；weight 固定 equal。
- 池 = 2×5×3×4 = **120 个**（`candidates.csv` 可复算）。**weight=volpar 不进主实验**：若先按 mode 排外层再截前 120，会全部落在 trend 上、零个 reversal，池子会失去方向多样性——这是本设计特意规避的点。volpar 只作为敏感性，未跑则在报告里声明。
- 两臂共享同一池、同一份日收益矩阵；**臂 B 不允许额外生成候选**。这是「固定预算」的全部含义。

## 5. 信号与组合构造

- 单品种信号：trend = sign(mom(L))，reversal = −sign(mom(L))；mom(L)=close/close.shift(L)−1。
- 过滤：ma20/ma60 要求价格在均线上/下方才允许对应方向；volcap 要求 20 日波动高于其 60 日中位数才开仓。
- 持有：hold ∈ {1,3,5} 日平滑——对目标仓位做 hold 日滚动均值（smoothing），不是「每 hold 日才更新一次」。
- 组合权重：equal = 1/n；volpar = (1/vol_i)/Σ(1/vol_j)，vol 为 20 日日收益标准差。
- 执行：信号 t 日收盘可得 → t+1 开盘建仓；收益用 close-to-close 并以 shift(1) 对齐；成本 = 换手 × 2bp（单边，常规假设，**非模拟赛实测**）。

## 6. 联合相似度（四路证据）

对任意两策略 i、j（只用 IS 段，避免偷看样本外）：

| 维度 | 定义 | 权重 |
|---|---|---|
| 代码/结构 | AST 骨架一致 + 参数向量的归一化 L1 距离（mode/L/hold/filter/weight 五维） | 0.30 |
| 信号 | 日度组合净仓位序列的 \|相关系数\| | 0.30 |
| 持仓 | 非零仓日集合的 Jaccard × 同向比例 | 0.20 |
| 收益 | 日收益序列的 \|相关系数\| | 0.20 |

联合相似度 `s_ij = Σ w_k s_k`。**不接受只做文本聚类或收益相关热图**：四路都要进，且权重冻结在本文。

## 7. 两臂规则

- 臂 A：IS Sharpe 降序取前 10。
- 臂 B：IS Sharpe 降序，贪心加入；若与已选集合中任一策略 `s_ij ≥ τ = 0.70` 则跳过；池子耗尽仍不足 10 个就按实际数量。
- 两臂都做等权组合（组合内不再做二次优化）。

## 8. 指标（预先定义，避免事后挑指标）

1. 有效策略数：对联合相似度做「≥0.70 归为一簇」的连通聚类，计所选集合覆盖的簇数；另报平均两两相似度。
2. 组合风险：年化波动、最大回撤、最差 20 日累计收益、所选策略两两收益相关的最大值。
3. 保留期表现（OOS）：组合 Sharpe、年化收益、最大回撤；以及「IS 第一名在 OOS 的排名分位」。
4. 稳定性：IS 内按年滚动（2018–2022 逐年重选），看两臂的年度有效策略数与风险是否同向。

## 9. 判据

- 「多样性约束有效」需同时满足：有效策略数上升；OOS 波动或回撤改善 ≥10%；且 OOS Sharpe 不明显恶化（不低于臂 A 的 0.8 倍）。
- 任一条件不满足即结论为「未观察到改善」，并写清是哪一条不满足——负结果同样交付。
- 检验能力：两臂各 10 个策略、OOS 约 700 个交易日，均值差的标准误约 1/√700 ≈ 0.038（年化约 0.6），所以小于约 1.2 个百分点的 Sharpe 差异不可分辨，必须在报告里写出这个门限。
